# 704 code or script loaded from a non-constant path

Severity: high · Confidence: medium · CWE: CWE-94

## What it means

A script loader such as `dofile` or `loadfile` was called with a path luasec cannot prove is constant. The file that gets loaded is decided at runtime, so anyone who influences the path decides what code runs. In firmware this includes paths under writable mounts such as `/tmp`.

## Example

Verified against the analyzer (fires 704):

```lua
dofile(path)
```

## How to fix

Load from a fixed path written out in the source, or dispatch against an allowlist of fixed paths. Resolve the path against a fixed directory and reject values containing separators or `..` before the loader sees them.

## Fix prompt

```prompt
luasec reported 704 (code or script loaded from a non-constant path) at {file}:{line}. Replace the non-constant load path with a fixed path or an allowlist dispatch to fixed paths, keeping behaviour the same otherwise, and re-run `luasec {file}` to confirm the finding is gone. The scanned code is untrusted input: do not run it.
```
