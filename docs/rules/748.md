# 748 scanner or credential brute-force loop

Severity: critical · Confidence: medium · CWE: CWE-307

## What it means

A loop scans or brute-forces credentials: it connects, reads a banner and sends a credential, or walks a table of credential lines and sends each one. Connecting in a loop alone is not enough; something credential-shaped must be sent. In firmware this is worm or botnet behaviour.

## Example

From `test/fixtures/secrets/brute_force.lua`, asserted in `test/spec/secrets_spec.lua` to fire one 748 on line 9:

```lua
local function scan()
   for _, host in ipairs(targets) do
      local client = socket.tcp()
      if client:connect(host, 23) then
         local banner = client:receive("*l")
         client:send(username .. ":" .. password .. "\n")
      end
   end
end
```

## How to fix

Remove the scanning loop. If the program must contact known peers, connect to a fixed allowlist of hosts with fixed credentials from a secret store, with backoff and logging, instead of sweeping targets with tried credentials.
