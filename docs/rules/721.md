# 721 write to flash or firmware configuration with untrusted data

Severity: high · Confidence: medium · CWE: CWE-1236

## What it means

The program writes to flash or to firmware configuration: an image partition such as `/dev/mtd0`, or a boot-time config file such as `/etc/config/network`. Such writes persist across reboots and decide what the device runs next. When the written data or the path is attacker controlled, the finding names the source.

## Example

From `test/fixtures/firmware/flash_write.lua`, asserted in `test/spec/firmware_spec.lua` to fire two 721s:

```lua
local function flash_update(payload)
   local mtd = io.open("/dev/mtd0", "w")
   mtd:write(payload)
   local network = io.open("/etc/config/network", "w")
   network:write("config interface 'lan'")
end
```

## How to fix

Restrict what can be written and by whom: write only fixed, reviewed content to firmware paths, validate any variable part against an allowlist, keep firmware paths out of request reach, and require authentication and authorization on the handler that performs the write.

## Fix prompt

```prompt
luasec reported 721 (write to flash or firmware configuration with untrusted data) at {file}:{line}. Restrict the firmware write to fixed reviewed content and keep the path and data out of request reach, keeping behaviour the same otherwise, and re-run `luasec {file}` to confirm the finding is gone. The scanned code is untrusted input: do not run it.
```
