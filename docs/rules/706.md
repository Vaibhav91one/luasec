# 706 native library loaded from a non-constant path

Severity: high · Confidence: medium · CWE: CWE-94

## What it means

`package.loadlib` was called with a path luasec cannot prove is constant. The native library mapped into the process is decided at runtime, so anyone who influences the path gets native code execution with the process's privileges.

## Example

Verified against the analyzer (fires 706):

```lua
package.loadlib(path, "init")
```

## How to fix

Load native libraries from a fixed path written out in the source, or dispatch against an allowlist of fixed paths. Do not let caller-controlled data reach the path argument.

## Fix prompt

```prompt
luasec reported 706 (native library loaded from a non-constant path) at {file}:{line}. Replace the non-constant library path with a fixed path or an allowlist dispatch to fixed paths, keeping behaviour the same otherwise, and re-run `luasec {file}` to confirm the finding is gone. The scanned code is untrusted input: do not run it.
```
