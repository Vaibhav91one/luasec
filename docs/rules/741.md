# 741 obfuscated code loader

Severity: critical · Confidence: medium · CWE: CWE-94

## What it means

Encoded or otherwise hidden data is decoded and handed to a code loader. The visible program carries no suspicious code; the payload only appears at runtime after decoding. In firmware this is the standard shape of a staged backdoor: a small visible loader plus a blob.

## Example

From `test/fixtures/payload/base64_loader.lua`, asserted in `test/spec/payload_spec.lua` to fire 741:

```lua
local blob = "b2NobyBoaQ=="

local function unpack_it()
   local payload = base64decode(blob)
   return loadstring(payload)
end
```

## How to fix

Remove the obfuscated loader and ship the code it would have loaded as plain, reviewable source. If the data must travel encoded, decode it as data and parse it with a fixed grammar instead of loading it as code.

## Fix prompt

```prompt
luasec reported 741 (obfuscated code loader) at {file}:{line}. Remove the obfuscated loader and ship plain reviewable source instead of decoding data into a code loader, keeping behaviour the same otherwise, and re-run `luasec {file}` to confirm the finding is gone. The scanned code is untrusted input: do not run it.
```
