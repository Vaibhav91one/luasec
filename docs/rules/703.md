# 703 dynamic code evaluation with a non-constant argument

Severity: high · Confidence: medium · CWE: CWE-94

## What it means

A code loader such as `load` or `loadstring` was called with an argument luasec cannot prove is constant. Whatever string arrives at runtime becomes code with the script's own privileges. In firmware this turns any influence over the string into arbitrary code execution.

## Example

Verified against the analyzer (fires 703):

```lua
loadstring(chunk)
```

## How to fix

Do not evaluate strings built at runtime. Replace the loader with direct code: a function call, a dispatch table of fixed functions, or a module loaded by literal name. If the string must be data, parse it as data instead of loading it as code.

## Fix prompt

```prompt
luasec reported 703 (dynamic code evaluation with a non-constant argument) at {file}:{line}. Replace the dynamic code evaluation with direct code such as a fixed function call or dispatch table, keeping behaviour the same otherwise, and re-run `luasec {file}` to confirm the finding is gone. The scanned code is untrusted input: do not run it.
```
