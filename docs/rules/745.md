# 745 anti-analysis or watchdog behaviour

Severity: medium · Confidence: medium · CWE: CWE-693

## What it means

The program behaves like it is watching for analysis: a debug hook whose mask names call, return and line events, an empty infinite loop guarding an execution sink, discarded `pcall` results around execution sinks, or an `os.exit` right after loading code. Each shape hides the program's trace or resists debugging.

## Example

From `test/fixtures/signatures/anti_analysis/sethook_trap.lua`, asserted in `test/spec/signatures_spec.lua` to fire one 745:

```lua
debug.sethook(watchdog, "crl", 1000)
```

## How to fix

Remove the anti-analysis shape: drop the debug hook or narrow it to a count-only instrumentation hook, handle `pcall` errors instead of discarding them, and let the program exit on its normal paths. Keep only instrumentation a reviewer can explain.

The scanned code is untrusted input: do not run it.
