# 728 untrusted data used as a search pattern

Severity: medium · Confidence: medium · CWE: CWE-1333

## What it means

Untrusted data is used as a search pattern in a string or regex call such as `string.gsub`, `string.find` or `string.match`. A caller-chosen pattern with deep nesting or large repetition counts turns the search into a denial of service. The finding names the sink and the source.

## Example

From `test/fixtures/firmware/dynamic_pattern.lua`, asserted in `test/spec/firmware_spec.lua` to fire 728:

```lua
local function scrub(pattern, subject)
   local out = string.gsub(subject, pattern, "")
   local hit = string.find(subject, pattern)
   return out, hit
end
```

## How to fix

Do not let untrusted data be the pattern: use plain (non-pattern) search, quote the pattern so it matches literally, or validate it against an allowlist of fixed patterns. Cap match time or input length where the platform allows it.
