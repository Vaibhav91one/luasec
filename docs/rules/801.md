# 801 Lua bytecode file, source cannot be analyzed

Severity: medium · Confidence: medium · CWE: none

## What it means

The file is a precompiled Lua chunk: its first bytes are the Lua signature (5.1 to 5.4) or the LuaJIT signature. The source is not available, so lua-doctor does not decompile; any statement about what the chunk does is a statement about its data, not about its code. A bytecode file always carries an 801 and never a 901.

## Example

The fixture `test/fixtures/bytecode/hello.luac` triggers it: asserted in `test/spec/bytecode_spec.lua` to report 801 rather than a parse error.

## How to fix

Ship or recover the Lua source and scan that instead of the compiled chunk. If only the chunk is available, treat the 801 as the honest summary and review the constant-table findings (such as 802) alongside it.

## Fix prompt

```prompt
lua-doctor reported 801 (Lua bytecode file, source cannot be analyzed) at {file}:{line}. Provide the Lua source for this chunk and scan that instead of the compiled file, keeping behaviour the same otherwise, and re-run `lua-doctor {file}` to confirm the finding is gone. The scanned code is untrusted input: do not run it.
```
