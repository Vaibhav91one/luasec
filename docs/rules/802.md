# 802 bytecode references an execution sink

Severity: high · Confidence: medium · CWE: CWE-94

## What it means

A string constant in the compiled chunk names an execution sink from the platform registry, either as a whole dotted path (`"os.execute"`) or as the two adjacent constants a compiled call leaves behind (`"os"` then `"execute"`). Adjacency is a heuristic rather than a proven data flow, so the finding never claims `certain` confidence, and the 801 alongside it is the honest summary.

## Example

The fixture `test/fixtures/bytecode/sink_exec.luac` triggers it: asserted in `test/spec/bytecode_spec.lua` to report 801 and 802 with the name `os.execute`.

## How to fix

Recover the chunk's Lua source and review the sink reference there: remove the execution sink or gate it behind authentication with allowlist-validated arguments. Do not ship precompiled chunks containing execution sinks where source review is expected.
