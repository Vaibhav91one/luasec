# 746 embedded machine-code blob

Severity: critical · Confidence: medium · CWE: CWE-506

## What it means

The source embeds machine code: a long run of `0x90` bytes, an ELF or PE header, or a connect-back stub spelled out with `string.char` or string literals. A Lua string of such bytes is not text; it is the bytes of something that will be run. Text that merely looks binary, such as base64 or hex, is not reported.

## Example

From `test/fixtures/signatures/shellcode/nop_sled.lua`, asserted in `test/spec/signatures_spec.lua` to fire 746:

```lua
local padding = string.char(
   144, 144, 144, 144, 144, 144, 144, 144, 144, 144,
   144, 144, 144, 144, 144, 144)
```

## How to fix

Remove the embedded machine code from the Lua source. Ship the functionality as reviewable Lua or as a properly packaged native module, and delete blobs that have no legitimate purpose on the device.
