# 749 persistence installed by the script

Severity: high · Confidence: medium · CWE: CWE-506

## What it means

The script installs persistence: appending to `/etc/rc.local`, writing a service under `/etc/init.d` or a systemd unit, installing a crontab, enabling a service, or adding a firewall rule that opens a port. Each of these survives a reboot, so the device stays compromised with nothing in the running process to show where it came from.

## Example

From `test/fixtures/signatures/persistence/rc_local.lua`, asserted in `test/spec/signatures_spec.lua` to fire one 749 on line 9:

```lua
local function install()
   local handle = io.open("/etc/rc.local", "a")
   handle:write(MARKER .. " &\n")
   handle:close()
end
```

## How to fix

Remove the persistence mechanism and use the firmware's legitimate update or service-management path instead. If the boot entry is legitimate, have it installed by the image build or package manager rather than by a script at runtime.
